📝 How to Edit

  1. Edit data/announcements.json directly on GitHub.
  2. Each announcement needs: id, text, start_date, expiry_date.
  3. Dates must be in YYYY-MM-DD format.
  4. Announcements only show if today is between start and expiry dates.
  5. Commit to main and GitHub Pages will update in seconds.
